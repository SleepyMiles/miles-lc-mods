# BunkbedRevive Forked
- This is a "fork" aka I added my own tweaks from the source ViViKo made available [here](https://discord.com/channels/1168655651455639582/1301621740312723537). Did this for my own modpack for me and my friends. Just wanted to fix some bugs that were reported. Tested it myself via 3 local instances and seems to be working fine? I do not promise any additional updates to this mod as it was for personal use, the original source is available, feel free to use it!

## Features
- Pick up a dead player's body and bring it to the bunkbed to revive
- Press E to revive them for a configurable cost
- Should work in multiplayer

### Configuration
Control how much revivals cost
- **Percentage of Quota**: Pay a percentage of the current quota (default: 30%)
- **Set Amount**: Pay a fixed amount of credits per revival

Control how many times players can be revived:
- **None**: Unlimited revivals (default)
- **Overall**: Limited number of revivals per round for the entire team
- **Per Player**: Each player has their own revival limit

Advanced restrictions
- **Teleported Bodies**: Choose whether bodies teleported via inverse teleporter can be revived
- **Mangled Bodies**: Choose whether bodies cut in half (Barber) or with the head off (Coil-Head, head burst) can be revived. Off by default, like the Defibrillator in Usual Scrap
- **Body Weight Requirement**: Control how much a body weighs

All settings can be configured via the config file or in-game with [LethalConfig](https://thunderstore.io/c/lethal-company/p/AinaVT/LethalConfig/).

More info can be found on the [modding discord](https://discord.com/channels/1168655651455639582/1192228011836186776)
