Install all

First time here?

  1. Download Miles Mod Helper (one small file).
  2. Open it and click Set up. If Windows says it protected your PC, click More info, then Run anyway.
  3. Come back here and click Install. Your browser asks to open the helper: allow it, and tick “Always allow” so it stops asking.

You need Gale with at least one Lethal Company profile. The helper only installs mods listed on this page, and checks each download before it touches Gale.
